# Finance-Quant-trade-SMA-Crossover-Backtester
💼 Project Name: Finance — SMA Crossover Backtester 🚀 What It Does This is a fully functional trading backtesting app It tests a Simple Moving Average (SMA) Crossover Strategy on any stock (like AAPL, TSLA, MSFT, etc.) using historical data fetched directly from Yahoo Finance. It downloads stock data. Computes fast and slow moving averages
